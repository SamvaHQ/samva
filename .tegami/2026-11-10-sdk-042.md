## Require Samva SDK 0.42

Both adapters now require `samva@^0.42.0` and validate against SDK 0.42.0.
Only the current SDK minor is supported; upgrade Samva alongside the adapter.

The adapter surface is unchanged. `@samva/email-sdk` still calls `email.send` and
`@samva/better-auth` still calls `messages.send`; neither payload changed in 0.42.
What changed around them:

- Organization-level email domains can be `shared`, so a namespace credential can
  send from a shared domain's senders.
- `email.setDefaultSender` takes a request body. Pass `{}` for the sender's own
  scope or `{ namespaceId }` for a namespace default.
